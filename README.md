# Padel Eyes

Padel tactics puzzles in 3D, seen from your own eyes on court. Plain HTML, CSS and JavaScript, no build step; three.js loads from a CDN.

- Run locally: `python3 -m http.server 3410`, then open http://localhost:3410
- Check every puzzle for physical sense: `node scripts/check-puzzles.js`
- Puzzles live in `js/puzzles.js`; each answer lists its sources.
